# PWA Icons

This directory should contain the following icon files for the PWA:

- `icon-192x192.png` - 192x192 pixel icon
- `icon-512x512.png` - 512x512 pixel icon

You can generate these icons using:
- Online tools like https://realfavicongenerator.net/
- Image editing software
- Or use a simple colored square as a placeholder

The icons should be square PNG images with transparent backgrounds (or solid backgrounds matching your theme).
